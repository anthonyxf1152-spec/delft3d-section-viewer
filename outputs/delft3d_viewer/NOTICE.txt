NEFIS reader notice
===================

nefis_reader.py is a scoped read-only Python implementation of the NEFIS 5
split-file disk layout, based on the documented parsing and access algorithms
in Deltares Delft3D MATLAB routines vs_use.m and vs_let.m.

Modification notice (2026-11-01):
The MATLAB layout/access algorithms have been reimplemented in Python for
read-only NEFIS 5 split .dat/.def files with one-dimensional map record groups.
The Python reader uses native 64-bit file seeking, reads one record/element at
a time, exposes metadata and NumPy arrays, validates layout sizes and pointer
chains, and includes an on-disk extent check for latest candidate records.
The reader is not the original Deltares software and has a smaller scope.
