# 时间层序交互程序

## 读取已保存三维含砂率模型

主窗口“三维显示”中的 **读取三维含砂率 NPY…**，以及地震窗口的 **Cigvis 查看已保存三维含砂率…**，均可读取上面保存的三维数组。地震窗口在刚保存完三维模型后会直接打开该目录。新窗口也可选择其他文件夹或 `sand_fraction.npy`，无需读取原始DAT/DEF或再次正演。

选择模型根目录，保留 `sand_fraction.npy`、`occupancy.npy`、`valid_xy.npy`、`x_m.npy/y_m.npy/depth_m.npy` 和参数文件。根目录三维含砂率按 **X,Y,depth** 排列，数值为0～1；不要选择 `xz/yz` 内的二维切片。

界面显示三维砂体外表面与YZ、XZ、XY切片。三条滑块/索引框控制固定X、固定Y和深度，标注实际坐标。可控制体表面阈值、透明度、显示分辨率和垂向显示夸张；阈值/分辨率修改后点击更新。含砂率色标与主窗口共用同一套三点设置。数据深度向下为正；保存模型中的物理层厚已经应用，不会在读取时重复缩放。

大NPY按只读内存映射读取，体表面和过大的切片仅在显示时抽样，源数组不变。只在有效列且有扇体占据率的位置显示含砂率。点击 **保存当前三维图与显示参数…** 输出PNG与JSON，记录源路径、完整网格、显示网格、实际切片坐标和色标。左键旋转、滚轮缩放、Shift＋左键平移。

可用 `python run_interactive.py --sand-model "模型文件夹"` 独立打开，不经过原始数据选择。

## 含砂率色标

“含砂率色标 / %”面板提供 **最小值、中间值、最大值** 及各自的 **颜色…** 按钮。默认配色从参考截图提取，为蓝紫、蓝、青、绿、金黄到亮黄的连续渐变，范围0/50/100%。修改后点击 **应用色标**：中间值映射到渐变中点，最小值和最大值映射到两端；例如10/35/90时，35%位于色带中央。有效数据超出显示范围时显示端点颜色，未知含砂率保持灰色。

点击某处“颜色…”会改用自定义三色渐变；点击 **恢复默认** 恢复参考色带及0/50/100。数值必须满足0≤最小值<中间值<最大值≤100。预览条与数字为当前草稿，应用后二维、已打开的三维含砂率剖面、地震正演含砂率输入图同步显示。设置在本机自动保存；导出的参数JSON包含 `sand_color_settings`。只更改显示映射，不改变原始含砂率、岩石参数或地震振幅。

## 当前切片地震正演

### 二维 PSF

“正演模式”可选 **二维 PSF（逐切片计算）**。XZ/YZ分别生成水平—深度物性网格并执行真正的二维PSF频域褶积，不创建面外三维物性体。修改参数后自动估算每个方向的网格、道数、内存和文件大小；也可点击估算按钮。窗口打开后先估算，点击计算才开始褶积。

正演前点击 **保存模型 .npy 并绘制六项物性…**，即可保存并在“二维六项物性”标签页查看：含砂率、速度Vp、岩石密度、声阻抗、孔隙度变化Δφ和反射系数。每个方向保存六个数值NPY、六张独立PNG和六联图，根目录保存所有切片的 `model_properties.png`。`model_parameters.json` 记录参数、种子、切片坐标、单位与轴序；`model_plot_settings.json` 记录绘图色标。

二维模式的 `xz/yz` 子目录中，数组顺序均为 **horizontal,depth**，并配 `horizontal_m.npy`、`depth_m.npy`、`valid.npy`、占据率与扇体顶底界。`computational_grid/` 保存含水平保护区的同一组二维模型，可复现正演输入。含砂率NPY数值为0～1、图中为%；声阻抗为当前Vp×密度，反射系数由相邻深度声阻抗计算，孔隙度图为变化量而非总孔隙度。NPY无需pickle即可载入。

正演完成后，地震与六项物性可切换标签查看；导出地震时会一并保存物性NPY及图片。二维模型保存不执行地震PSF，之后以同参数和种子正演可复现输入。二维场不含面外响应，每个方向使用二维孔隙度相关场，与三维体切片不会完全相同。泥沙补全源缓存仍可能占用较多内存。

### 三维模式与通用参数

在主窗口选定时刻、X/Y、方向和半宽，点击“当前切片地震正演…”。窗口先估算当前网格；点击“计算当前切片地震”后在后台运行，结果依次显示含砂率、原岩石参数PSF响应、内部非均质PSF响应。主窗口换时刻或位置后，再点一次按钮取得新快照。

**正演前估算与保存模型：**参数修改后，网格信息自动刷新，也可点击“估计当前参数的网格大小”。显示 X×Y×Z 样点数、体素数、单个 float32 数组大小、建模/正演峰值内存估算、磁盘占用以及当前 XZ/YZ 道数。超过2200万样点时禁用正演；三维模型保存仍可使用，不必为保存数组而降低网格分辨率。估算不读取三维物性，不执行褶积，实际层位深度范围在建模时检查。

三维保存使用XY分块生成与写盘，面板另显示“分块保存内存”和块数。每个输出NPY仍是完整的 **X,Y,depth** 三维数组，并配坐标、有效掩码、当前切片和参数。孔隙度滤波包括相邻块保护区，数值与同网格的整体建模一致。保存前检查磁盘空间，写入失败会清理本次临时目录；保存过程不运行PSF。超过正演上限时，保存成功提示会明确“模型已完整保存”。较大文件建议使用 `np.load(..., mmap_mode='r', allow_pickle=False)`。

点击“生成并保存当前模型 .npy…”可在运行地震前单独保存当前参数的模型。选择保存位置后，程序新建独立文件夹，保存 `sand_fraction`、`occupancy`、`vp_m_s`、`density_kg_m3`、`impedance_kg_m2_s`、`porosity_delta`、`reflectivity`、`baseline_reflectivity` 各自的 `.npy`，前三维均按 **X,Y,depth** 排列；深度向下。另存 `x_m.npy/y_m.npy/depth_m.npy`、`valid_xy.npy` 和扇体顶底深度。`xz/yz` 子目录为本次所选切片，二维数组按 **horizontal,depth** 排列。`model_parameters.json` 保存参数、种子、时刻、单位、坐标约定、数组形状与切片固定坐标。使用 `np.load(..., allow_pickle=False)` 读取，较大模型可用 `mmap_mode='r'`。

三维有效区由 `valid_xy.npy` 标识；无效列是计算支撑，不应作为有效观测。速度、密度、声阻抗和反射系数已经应用当前内部非均质强度；`baseline_reflectivity` 是调整前的原岩石参数反射系数。含砂率数组数值为0～1、按整个体素计量，边界部分体素另有占据率 `occupancy`。保存模型不运行 PSF，同样参数与种子可用于随后正演。更改参数后另存新文件夹，不覆盖旧模型。

默认30 Hz、物理层厚16倍、统一埋置参考深度1400 m、最大深度1800 m。可调整主频、厚度倍率、埋深、孔隙度非均质强度、含砂率来源及采样。厚度倍率改变正演的物理厚度，与三维显示夸张无关；设为1表示不放大。原始局部起伏保留，先拟合一张初始区域参考面再转深度，不拉平最终顶面；初始砂床按参考方案排除。

输入含砂率不因内部非均质而改变；孔隙度情景先改变速度和岩石密度，再计算反射系数并作有限带宽/倾角三维PSF褶积。强度1对应孔隙度绝对变化不超过0.025，强度0时两套响应一致。PSF参考速度默认2800 m/s。它是成像域近似，岩石参数未作实测测井标定。

默认采用共同红白蓝振幅色标，无逐道AGC。可调整共同色限，或叠加输入顶底界。修改物理参数须重新计算，导出按钮在更新前保持禁用。导出包括PNG、XZ/YZ的NPZ（速度、岩石密度、孔隙度变化、反射系数、两套地震、输入含砂率、坐标、有效掩码）和完整参数JSON。含砂率补全来源与原层序解释限制继续适用，缺失期次未补造。

## 启动与层序操作

安装环境后，双击仓库根目录的**`start.cmd`**即可启动。也可在本目录打开已激活Conda `delft3d`环境的终端运行：

```bat
python run_interactive.py
```

在PyCharm中选择已安装依赖的Conda `delft3d`解释器，打开并运行`run_interactive.py`。首次使用会显示数据源对话框；点击“浏览…”选择DAT和配套DEF，检查砂泥组分及干床密度，再点击“读取并绘图”。主窗口上方的“打开 / 合并 DAT / DEF 结果…”可以切换项目；失败或取消时保留当前结果。

**合并多期接续模拟：**在打开窗口勾选“合并多期次接续结果”，用“扫描文件夹…”或“添加 DAT…”加入数据，按实际接续顺序排列。已有累计时间时选择第一个时间模式；各期重新计时时选择第二个模式。共同网格、有效单元及床层底界必须一致，接续锚点须通过床面、砂泥库存校验。累计时间发生重叠时，从共享首帧起采用后一期，替换前一期尾段；共享帧只保留一次。存在较长的保存间隔时提示缺失区间并保留其真实时长，不插值。主窗口显示源文件及原记录编号，导出 `selection.json` 中的 `source_project` 保存完整映射与校验报告。后一期侵蚀会参与前期层面截切，二维和三维沿同一个合并时间轴工作。

本机已确认顺序：`trim-sanqi → trim-erqi → trim-san → trim-siqi`，累计时间模式；`trim-san` 从水动力第27天接续并替换前一期重叠尾段，第28.25至31天之间无中间保存记录。合并不改写原始DAT/DEF，不能补回缺失期间的具体过程。

**灰色缺测补全：**现在默认选择“分期估算＋缺测补全”，三维默认选择“分期含砂率＋缺测补全”。选择时刻和位置后点击“更新剖面”即可查看；切换时刻首次计算约需10–20秒，同一时刻换位置会复用结果。要查看原始缺测，切回“分期净增量估算”。

补全保留所有原有有效值，优先采用同一保存阶段、同一连续沉积区域内2km范围最近最多8个有效网格的距离平方反比加权值；没有合适邻域时，采用该位置、该保存阶段的实际混合床平均含砂率。插值基于全局XY网格，两个方向交点一致，并且不引用所选时刻之后的数据。2km和8邻点是显示估算参数，未经独立岩性资料校准；补全图用于连续展示，不能当作恢复的真实分层组分，也不保证地层砂量收支闭合。图题明确标注“缺测补全”。

1. **选择时刻。**左侧下拉框、滑块或“上一时刻／下一时刻”选择实际保存的记录，同时核对形态时间和水动力时间。记录从0开始。较早时刻会仅使用截至该时刻的原始床面重新计算幸存界面，不截取最终时刻层序。
2. **指定位置与方向。**手动输入全局X、Y，单位为**米**；或点击平面图、上中下部参考按钮。参考按钮按有效网格位置选点，不自动识别内中外扇。XZ固定Y、沿X展开，YZ固定X、沿Y展开；“XZ与YZ两者”同时绘两条。剖面采用最近原始网格中心，实际坐标与偏差显示在标题和下方说明中。
3. **设置窗口并更新。**“剖面半宽”单位为**km**，默认**6**，即中心两侧各6km、合计约12km，到模型边缘时截断。修改时刻、手动坐标或方向后，点击“更新剖面”；**平面图点选会立即更新**。右侧每个方向并排显示时间层序与含砂率，因此选择两个方向时有两张层序图、两张含砂率图。点选前应退出图形工具栏的平移／缩放模式。
4. **调整Colorbar及二维含砂率。**左侧分别控制“沉积阶段 / 天”和“床面高程 / m”。选择“全时段统一”便于不同时刻之间比较；选择“随当前时刻”，每次换时刻会自动更新上下限；选择“手动范围”后输入下限、上限，再点击“更新剖面”。沉积阶段的范围用于二维层序剖面、Cigvis层面；三维剖面选择“保存阶段”时也使用此范围。床面高程范围用于左侧平面定位图。“二维含砂率”可选“分期估算＋缺测补全”“分期净增量估算”或“当前混合床平均”；两张含砂率图使用统一的参考配色，可在“含砂率色标 / %”面板调整最小值、中间值和最大值。分期净增量模式以灰色标出无法可靠估算的层段；混合床平均模式来自所选时刻保存的单个混合床层，垂向数值一致。手动色标范围须满足上限大于下限。
5. **查看三维及含砂率。**在“三维剖面着色”选择“保存阶段”“当前混合床平均含砂率”“分期净增量估算含砂率”或“分期含砂率＋缺测补全”，点击“Cigvis三维展示”。左屏为所选时刻的时间层面选集，右屏按所选变量着色，含砂率色标与二维和地震输入图共用同一套三点设置。当前混合床平均含砂率来自该时刻的实际床内库存，整柱只有一个混合床层；分期净增量含砂率通过砂和泥各自质量差除以干床密度得到的等效厚度计算，只有两组分均非负增长、总量与床面增厚闭合的区间才赋值。缺测补全模式使用上文的方法。后期侵蚀截切的是几何层序，分期增量组成仍不能当作最终幸存地层的实测岩性。左键拖动旋转、滚轮缩放、Shift＋左键拖动平移。默认抽选10个层面，不透明度0.38；显示垂向夸大默认500，只改变观看比例。三维轴为全局X、Y千米及正向上高程千米。
6. **导出。**点击“导出当前结果”，同样会自动应用当前参数，另建`exports/record_记录号_日期时间/`唯一目录。`selection.json`和`cigvis_3d.json`记录当前色标模式与范围。导出完毕会显示完整保存位置。

操作例：选择**记录120**，输入**X=37980m、Y=35590m**，半宽设为**6km**，方向选**“XZ与YZ两者”**，点击“更新剖面”，再打开三维或导出。XZ使用输入Y附近的实际网格行，YZ使用输入X附近的实际网格列，两条都保留输入位置及取最近网格的误差。

坐标输入范围随所选文件的实际网格更新；在平面图有效区域选点。各导出目录包含：

| 文件 | 内容 |
|---|---|
| `sections.png` | 平面定位图、XZ/YZ时间层序剖面及对应的XZ/YZ含砂率剖面 |
| `cigvis_3d.png` | 当前参数下的三维截图 |
| `xz_section.npz`、`yz_section.npz` | 各方向的原始坐标、床面历史、推断界面等数组 |
| `xz_interfaces.csv`、`yz_interfaces.csv` | 保存阶段、时间、横向坐标、界面高程及区间厚度 |
| `selection.json` | 请求位置、实际剖面、时刻与参数 |
| `cigvis_3d.json` | 三维界面选集、坐标、显示设置与验证信息 |
| `xz_sand_fraction.npz`、`yz_sand_fraction.npz` | 始终随二维含砂率图输出；数值0–1，`supported`只标记原有库存支持的值，补全值仍为False |

只选一个方向时，仅生成该方向的NPZ与CSV。

补全模式的含砂率NPZ额外保存`raw_fraction_0_1`（补全前）、`filled_mask`（补全位置）、`fill_source`及`fill_settings_json`。来源码1为原有有效估算或初始床，2为空间插值，3为当期混合床均值补齐，0为无层段或仍缺失；这些码不代表置信概率。厚度小于1mm的区间不显示在二维含砂率图中。原始Delft3D数据和库存缓存保持不变。

默认沉积阶段色标覆盖完整保存时段，便于比较不同时刻；标签为“保存沉积阶段”，不是精确成层年龄。初始床层底界使用实际源底确定。界面稀疏化、不透明度与显示夸大均属显示设置，不更改接口缓存。

结果为**床面时间序列推断的幸存几何层序**。当前算法要求一个垂向混合床层，输出间隔内冲淤过程未知；分期含砂率与缺测补全均为估算，细色带不能当作直接保存的真实地层。部署、格式限制及缓存说明见仓库根目录README。
