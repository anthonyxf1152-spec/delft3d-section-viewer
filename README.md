# Delft3D 时间层序与含砂率交互查看器

在 Windows 桌面中选择一组 Delft3D `.dat/.def` 结果，按保存时刻及平面点选位置绘制 XZ、YZ 层序和含砂率剖面，并用 CIGVis 查看三维层面与剖面。每组源文件使用独立缓存，切换结果后重新读取网格和时间轴。

## 新电脑配置

推荐 Windows 10/11 64 位、Python 3.12、可用的 OpenGL 显卡驱动及可写的本地磁盘。内存和缓存空间取决于“保存时刻数 × 网格数”；较大项目建议至少 8GB 内存并在 SSD 上保留数 GB 空间。二维绘图使用 Matplotlib；三维绘图使用 CIGVis、VisPy 和 PySide6，需要目标桌面能够创建 OpenGL 上下文。[VisPy 安装文档](https://vispy.org/installation.html)说明了 GUI 后端要求。

1. 从 [Miniconda 官方安装页面](https://www.anaconda.com/docs/getting-started/miniconda/install)安装 Windows x86_64 版本，也可使用已有 Anaconda。无需在 PyCharm 中另装一套 Anaconda。
2. 从 GitHub 下载整个仓库 ZIP 并完整解压，或使用 `git clone`。不要只复制某个 `.py` 文件。建议保存到如 `D:\Delft3DViewer` 的可写目录。原始模拟结果可放在其他磁盘。
3. 打开 **Anaconda Prompt**，进入解压后的仓库根目录，再创建环境：

   ```bat
   cd /d D:\Delft3DViewer
   conda env create --file environment.yml
   conda activate delft3d
   python check_environment.py
   python check_environment.py --render
   ```

   环境安装需要联网，YAML 中不包含本机绝对安装路径。`conda env create --file` 是兼容现有 Conda 的创建方式，见 [Conda 环境管理文档](https://docs.conda.io/projects/conda/en/stable/user-guide/tasks/manage-environments.html)。也可双击根目录 `install_environment.cmd`，该脚本创建同名环境并检查依赖。
4. 启动：

   ```bat
   conda activate delft3d
   python outputs\time_stratigraphy_preview\run_interactive.py
   ```

   以后可以双击根目录 **`start.cmd`**。如果 Conda 装在自定义位置，请从 Anaconda Prompt 运行启动脚本，或设置 `DELFT3D_PYTHON` 为该环境 `python.exe` 的完整路径。程序使用内置的只读纯 Python NEFIS 5 读取器，**不需要额外安装 NEFIS DLL，也不需要在新电脑上安装完整 Delft3D 来读取结果**。

## 含砂率配色与三点色标

含砂率统一使用从参考截图提取的蓝紫—蓝—青—绿—金黄—亮黄色渐变；图中数据单位仍为含砂率百分比。主窗口和地震正演窗口都有 **含砂率色标 / %** 面板，可设置最小值、中间值、最大值，点击 **应用色标** 同步更新二维、已打开的三维含砂率剖面及地震输入含砂率图。默认0%、50%、100%。

中间值是真正的颜色映射中点：例如10%、35%、90%时，35%对应渐变的中央颜色，低于10%或高于90%的有效数据分别显示端点颜色。未知含砂率仍以灰色单独表示。须满足 `0 ≤ 最小值 < 中间值 < 最大值 ≤ 100`。

各数值旁的 **颜色…** 可修改对应颜色，改色后使用自定义三色渐变；**恢复默认** 恢复参考配色及0/50/100。预览条展示当前草稿，修改后需点击应用。设置自动保存到本机，重启后恢复；主窗口和地震窗口共用一套已应用设置。修改含砂率色标只重绘显示，不重新计算地震、不改变含砂率或振幅数组。二维、三维和地震导出的参数JSON均记录已应用的 `sand_color_settings`。

## 当前切片地震褶积正演

### 读取已保存的三维含砂率 NPY，用 Cigvis 查看

主窗口 **4 Cigvis 三维显示 → 读取三维含砂率 NPY…**，或地震窗口 **Cigvis 查看已保存三维含砂率…**，可打开已经保存的三维模型。刚保存完三维模型时，地震窗口会直接打开这次保存的目录；也可以在新窗口选择其他模型文件夹或 `sand_fraction.npy`。该功能不需要重新正演，也不依赖原始DAT/DEF。

请选择模型**根目录**，其中需要 `sand_fraction.npy`、`occupancy.npy`、`valid_xy.npy`、`x_m.npy`、`y_m.npy`、`depth_m.npy`；同目录的 `model_parameters.json` 会提供网格和原切片位置。NPY顺序必须为 **[X,Y,depth]**、含砂率为0～1、深度向下递增。不要选择 `xz/yz` 子目录内的二维切片。

窗口显示三维砂体表面及 **YZ固定X、XZ固定Y、XY固定深度** 三个切片。可通过滑块或索引数字调整位置，控件下方显示实际坐标；勾选框可隐藏单个切片。可调整体表面最低含砂率、显示分辨率、不透明度及垂向显示夸张。修改阈值或分辨率后点击 **更新体表面**；色标与主程序共用最小值/中间值/最大值和颜色。左键旋转、滚轮缩放、Shift＋左键平移，点击 **复位三维视角** 可恢复观察方向。

含砂率仅在有效网格且 `occupancy>0` 处显示，围岩不作为砂体。三维外表面由选定阈值和显示分辨率重建，细层可能因显示抽样而省略；大平面也有显示样点上限。原始NPY通过只读内存映射访问，不改变数组或重新放大物理层厚。体表面的采样网格、切片实际坐标、阈值、颜色、显示夸张和相机方向会随 **保存当前三维图与显示参数…** 输出为PNG及同名JSON。

也可独立打开，跳过原始数据选择：

```bat
python outputs/time_stratigraphy_preview/run_interactive.py --sand-model "保存三维模型的文件夹"
```

### 二维 PSF 与六项物性模型

正演窗口的 **正演模式** 可选择 **二维 PSF（逐切片计算）** 或原有三维模式；首次使用新模式时默认二维。二维模式分别在当前 XZ/YZ 的水平—深度网格上建模和执行二维FFT PSF褶积，含水平保护区，不分配垂直于切片方向的三维物性体。水平、垂向采样、主频、埋深、层厚倍率、非均质强度及随机种子均可修改。参数修改后自动更新网格估算，也可手动点击估算按钮；显示每个方向的计算网格、可见切片道数、数组大小、峰值内存及磁盘估算。原始分期含砂率补全仍可能需要时间—XY源缓存的内存。

正演之前点击 **保存模型 .npy 并绘制六项物性…**，选择保存位置。程序按当前参数生成模型，切换到 **二维六项物性** 标签页，并在独立目录保存：

- `xz/`、`yz/`：当前二维切片的 `sand_fraction.npy`、`vp_m_s.npy`、`density_kg_m3.npy`、`impedance_kg_m2_s.npy`、`porosity_delta.npy`、`reflectivity.npy`，并附 `occupancy.npy`、`baseline_reflectivity.npy`、`horizontal_m.npy`、`depth_m.npy`、`valid.npy`、扇体顶底界。
- `xz/computational_grid/`、`yz/computational_grid/`：含水平保护区的同一套二维数组，可复现PSF输入；主切片目录仅保存窗口显示范围。
- `model_properties.png`：所有切片的六项物性对比；每个方向还保存自己的六联图，以及与六个物性数组同名的独立PNG。
- `model_parameters.json`：当前模式、完整参数、随机种子、实际切片坐标、网格、单位和每个数组的轴序；`model_plot_settings.json` 保存绘图色标。

二维数组统一按 **[水平道, 深度样点]** 排列，深度向下。含砂率保存为0～1，图中显示百分比；边界体素按整个体素计量并附占据率。孔隙度变化是 **Δφ**，不是总孔隙度。有效列由 `valid.npy` 标识。声阻抗严格为修改后Vp×密度；反射系数沿深度按相邻声阻抗差/和计算。NPY为普通数值数组，使用 `np.load(path, allow_pickle=False)` 即可载入。频率和PSF参考速度控制褶积响应；岩石参数受物性情景、几何和采样参数控制。

点击 **计算当前切片地震** 后，在 **地震 PSF 正演** 标签显示含砂率、原岩石参数及内部非均质PSF响应；**二维六项物性** 标签显示相应输入。**导出地震剖面与参数** 同时导出二维NPY、地震NPZ、地震图及六项物性PNG。模型独立保存不执行PSF褶积，修改参数后可以另存新目录。

二维PSF采用水平波数—垂向波数二维传递函数、零相位Ricker频带及25°～40°渐消倾角窗。它不含面外响应，也不是全波动方程。各方向使用各自二维相关孔隙度场，因此二维结果与三维体切片不必相同，XZ/YZ交点的非均质物性也不要求一致。原始层序起伏和输入含砂率不因显示配色变化。

### 三维模式与通用参数

选好保存时刻、位置、剖面方向与半宽后，点击左侧 **当前切片地震正演…**。窗口先显示当前参数的网格估算，点击 **计算当前切片地震** 后在后台正演，按行显示 XZ／YZ，三列依次为当前切片含砂率、原岩石参数地震和内部非均质地震。第三列对应所给参考图的模型思路与显示方式。改变主窗口时刻或位置后，再点击该按钮获取新的切片快照。

**正演前网格与模型：**修改参数后，网格估算自动刷新，也可点击 **估计当前参数的网格大小**。显示精确的 X×Y×Z 样点数、体素总数、每个 float32 数组大小、建模与正演峰值内存估算、模型文件磁盘占用及 XZ/YZ 切片形状。内存为估算值，应另留运行余量。**2200万样点限制仅用于正演；三维模型保存不受这个数量限制。**形态层位是否超出所设深度范围仍在生成模型时检查。

三维保存采用 **XY分块计算、写入完整形状的 NPY**：例如711×801×51即使超出正演上限，仍可点击 **保存模型 .npy 并绘制六项物性…**。正演按钮在超限时禁用，保存按钮继续可用；估算面板另列分块保存内存与块数。输出保持标准三维 `[X,Y,depth]` 数组，包含所有物性、坐标、有效掩码、当前切片和参数文件。每块只在邻域带内生成和滤波孔隙度噪声，保护区使分块边界与整体现有模型一致。先检查磁盘空间，在临时目录完成全部文件后才发布；原目录不会被覆盖。保存后仍会绘制切片六项物性，不执行PSF。`model_parameters.json` 中 `streaming_save` 记录分块方式，`convolution_performed` 为false。读取大数组建议使用 `np.load(path, mmap_mode='r', allow_pickle=False)`。

点击 **生成并保存当前模型 .npy…**，选择保存位置，程序在独立新文件夹中生成按当前参数修改后的模型，无需先运行地震褶积。三维数组按 **[X,Y,depth]** 排列，深度向下；包括 `sand_fraction.npy`（0～1）、`occupancy.npy`、`vp_m_s.npy`、`density_kg_m3.npy`、`impedance_kg_m2_s.npy`、`porosity_delta.npy`、`reflectivity.npy` 和 `baseline_reflectivity.npy`。同时保存 `x_m.npy`、`y_m.npy`、`depth_m.npy`、有效网格掩码 `valid_xy.npy`、扇体顶底深度。`xz/`、`yz/` 子目录保存当前所选切片，数组按 **[horizontal,depth]** 排列，实际固定坐标记录在 `model_parameters.json`。无效列使用掩码排除；它们是计算支撑区，不能视为观测模型。文件全部为普通数值数组，可用 `np.load(path, allow_pickle=False)` 读取，较大数组可另加 `mmap_mode='r'`。

`model_parameters.json` 记录完整参数、随机种子、时刻、坐标、单位、每个数组的形状与轴序。这里的 Vp/密度/反射系数是已应用当前非均质强度后的模型，`baseline_reflectivity` 为施加内部孔隙度变化前的反射系数。修改参数后可再次保存新模型；已有目录不会被覆盖。相同切片、参数与随机种子用于后续正演时，物性模型可复现。

默认参数为 **30 Hz、物理层厚16倍、埋置参考深度1400 m、深度范围0～1800 m、125 m XY采样、5 m Z采样、2800 m/s PSF参考速度**。这是参考图片采用的研究情景；物理层厚倍率会改变参与正演的实际厚度，与主窗口三维显示夸张相互独立。可设为1查看原始厚度下的响应。深度通过一张拟合于最早床面的区域平面转换，不逐柱拉平最终顶面；正演情景按参考方案排除初始砂床。

内部非均质在含砂率不变的情况下加入有界孔隙度情景，再计算 `Vp × 岩石密度` 的声阻抗、相邻深度样点的反射系数和三维PSF褶积。非均质强度为1时，孔隙度变化上限为±0.025；设为0可验证两列地震一致。速度和岩石密度采用参考项目中的假设公式，界面的岩石密度不同于数据导入时的泥沙干床密度。

程序使用与参考代码相同的有限带宽、25°～40°渐消倾角窗PSF，计算包含邻域的三维局部体后，在主窗口实际取样坐标处提取剖面。内部相关场采用固定全局坐标与种子，便于多次切片复现。由于当前合并地层、补全方法和随机场实现不同，不承诺逐像素复现旧图。模型中的细层条纹来自岩石参数情景，不是叠加在地震图上的噪声。

正演的含砂率输入可选择“分期估算＋缺测补全”或“当前混合床平均”；前者仍包含估算。缺少有效组分的有厚度层段会拒绝计算，避免把未知值当作泥岩。背景围岩层理是单独的岩石物理假设。缺失保存期次不会因地震正演而恢复。

两列地震默认使用参考图相同的红白蓝色谱和共同色限±0.07248，无逐道AGC。可调整色限或勾选输入顶底界；修改正演参数后须重新计算，旧结果不能以新参数导出。**导出地震剖面与参数** 保存PNG、每个方向的NPZ（含含砂率、Vp、岩石密度、孔隙度变化、反射系数、两套地震、坐标和有效掩码）及完整参数JSON，默认位于现有导出目录。

该方法是**成像域PSF褶积近似**，不求解完整波动方程；不包含多次波、完整散射、采集过程或衰减Q。岩石参数及物理厚度均为研究假设，不是测井标定的真实地下模型。首次运行耗时取决于切片范围与含砂率补全；较大范围需缩小半宽或增大XY采样，原始文件保持只读。

## 多期次接续模拟合并

在主窗口点击 **打开 / 合并 DAT / DEF 结果…**，勾选 **合并多期次接续结果**。可以添加多个 DAT，或用 **扫描文件夹…** 查找同名配套 DEF；用上移、下移或拖动确认真实期次顺序。扫描按源文件的首个水动力时间添加，时间相同或各期重新计时的文件仍须手动排序。

- 文件保留了累计时间时，选择 **文件已有累计时间**。后一期开头必须与前一期的同时间记录床面、砂泥库存及形态时间一致，才允许从该锚点替换前一期重叠尾段。共享锚点只保留一次。这里的替换只发生在查看器缓存，不修改源文件。
- 各期时间重新起算时，选择 **各期重新计时**。程序校验前一期末帧和后一期首帧的床面与砂泥库存，再分别累加水动力、形态时间并去掉共享首帧。这个模式假定两期直接接续，不包含额外停歇时间。
- 各期必须具有相同网格、有效单元、床层底界和泥沙组分定义，使用共同的砂泥干床密度。若仅传递地形、重置了底床库存或换了网格，会明确拒绝直接合并。
- 累计时间中缺失的保存记录不会被插值补造。较长的期次边界间隔会在界面提示；这段时间内的具体冲淤过程无法从现有输出恢复，层段只代表两次保存之间的净变化。
- 合并后沿统一时间轴重建层序，因此后期侵蚀也会截切前期层面。二维、三维、含砂率及现有导出功能共用这个合并模型。当前时刻显示其源文件和原记录编号，导出 JSON 保留期次、接续校验、时间偏移和来源映射。

本机 `数值模拟` 文件夹中的已核验顺序为 **trim-sanqi → trim-erqi → trim-san → trim-siqi**，使用累计时间模式。`trim-san` 从水动力第 27 天接续并替换 `trim-erqi` 的后续重叠记录；第 28.25 至 31 天没有提供中间保存记录。文件名中的中文期次拼音不作为排序依据。

## 首次打开数据与切换项目

1. 新电脑首次启动后会出现“打开 Delft3D 结果文件”对话框。在 `.dat`、`.def` 路径旁分别点击“浏览…”，会打开 Windows 文件选择窗口；选择结果数据 `.dat`，再确认其配套 `.def` 文件。
2. 点击“检查文件并读取泥沙组分”，确认砂、泥组分及其干床密度。旧项目中使用的砂 `1600 kg/m³`、泥 `500 kg/m³` 仅是该项目参数；新项目应依据对应 `.sed` 文件或模型设置填写。干床密度与颗粒密度不是同一个量。
3. 点击“读取并绘图”，等待校验和缓存构建。读取在后台线程中进行。首次导入大文件可能需要较长时间；再次打开同一组未变化的文件会复用缓存。不同源文件或组分设置使用独立缓存。
4. 在主窗口点击“打开 / 合并 DAT / DEF 结果…”可再次选择另一组源文件，或勾选多期次合并。新结果的网格范围、时刻数量和初始选点会重新设置；“上部参考／中部参考／下部参考”按当前有效网格定位，不自动判定真实内扇、中扇、外扇。
5. 选择时刻、输入 X/Y 或点击平面图，再点击“更新剖面”。XZ 固定 Y 沿 X 展开，YZ 固定 X 沿 Y 展开；可同时绘制两个方向。坐标单位为米，横轴图示为千米，高程正向向上。
6. 右侧同时显示时间层序剖面和含砂率剖面。“二维含砂率”可切换分期净增量、估算补全及混合床平均。缺测补全使用同一阶段邻域，缺少邻域时采用该位置当期混合床平均值；补全位置和来源写入导出数据。
7. 点击“Cigvis三维展示”查看同一时刻的位置剖面；左键旋转、滚轮缩放、Shift＋左键平移。点击“导出当前结果”保存 PNG、NPZ、CSV 和参数 JSON。

关于色标、输出文件以及分期含砂率的含义，见 [详细交互使用说明](outputs/time_stratigraphy_preview/README_交互程序.md)。输出是原生网格上按最近单元提取的剖面，实际采用的固定坐标和偏差会显示在界面中。

导入缓存默认位于 `%LOCALAPPDATA%\Delft3DTools\Delft3DSectionViewer\source_cache`（以本机 Qt 返回的用户应用数据目录为准）。缓存中的路径和数据只保存在本机；Qt 的最近使用设置保存在当前用户配置中。导出默认位于 `outputs/time_stratigraphy_preview/exports`，可用入口参数 `--export-root` 指定其他可写目录。新电脑代码包不附带旧电脑缓存，必须自行选择模型文件。

2. 在 **Settings → Python Interpreter → Add Interpreter** 中选择现有本地 Conda 环境 `delft3d`，不要重新创建第二套环境。菜单名称可能随 PyCharm 版本变化，见 [PyCharm 解释器配置文档](https://www.jetbrains.com/help/pycharm/configuring-python-interpreter.html)。

## 支持范围与结果解释

当前读取器面向 **Delft3D NEFIS 5 分离式 `.dat/.def` map 输出**。网格须为以米为单位、与 X/Y 轴对齐的笛卡尔矩形网格，时间与泥沙输出应同步。当前层序与含砂率流程要求**恰好两个泥沙组分、一个保存的混合床层**，通过界面指定哪一个是砂、哪一个是泥；旋转/曲线网格、多组分/多层床存储、其他 NEFIS 版本、NetCDF 或普通文本 `.dat` 不会自动转换为兼容输入。程序遇到不支持的结构会给出错误信息。

层序由床面时间序列推断。分期含砂率由相邻保存时刻组分库存差估算，混合床平均值来自所选时刻实际库存，缺测补全是连续展示所用的估算。原模型只保存一个混合床层，因此这些图不能作为恢复真实层内岩性或证明分层砂量收支闭合的依据。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击后找不到 Conda | 从 Anaconda Prompt 启动，或设置 `DELFT3D_PYTHON`；解释器路径由 `python -c "import sys; print(sys.executable)"` 查询。 |
| `No module named ...` | 检查当前/PyCharm 解释器是否为 `delft3d`，重新执行环境检查。 |
| 三维白屏或 OpenGL 错误 | 在目标桌面运行 `python check_environment.py --render`；更新显卡驱动后重试。远程桌面或虚拟机的 OpenGL 支持取决于其配置。 |
| `.dat` 无法读取 | 确认是 NEFIS 5 map 数据，并选择匹配的 `.def`；普通文本 `.dat` 不属于此格式。 |
| 密度或库存闭合校验失败 | 根据模型 `.sed` 设置确认所选砂泥组分和干床密度，避免把颗粒密度当作干床密度。 |
| 模拟仍在写文件 | 优先选模拟已完成并关闭后的结果；输入在读取期间变化时校验会中止。 |
| 首次导入或补全较慢 | 初次需要建立床面与组分缓存；补全首次需要对当前时刻的完整网格计算，同一时刻换剖面会复用结果。 |
